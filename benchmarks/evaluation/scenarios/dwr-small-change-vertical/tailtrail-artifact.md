# DWR-4 small-change vertical

An approved small change is bound to its requirement ID before work begins.
The host records factual source-edit evidence and a passing focused validation
receipt. TailTrail derives the checkpoint, completion review, and requirement
fulfilment assessment only from those saved facts. That requirement fulfilment
assessment is linked to the approved boundary.

The canonical Completion Report remains the single closure authority. DWR-3
then creates a completion receipt only when that report is complete. The
vertical has no retry; it never edits source on its own and never asserts an
unrecorded test result.
All scenario claims are local-evidence from deterministic saved artifacts.
