# PM-L5 Learning Calibration And Proof Design

The closed, SHA-256-sealed catalog contains paired control and learning metrics
for at least four later-observed scenarios in each of the seven V3 classes. The
evaluator deterministically calculates class and aggregate classification,
calibration, correction, review-time, and token metrics. Fixture evidence always
produces an empty publishable-claims list.

Optional project calibration joins only active, chain-validated PM-L3 decisions
and later categorical attributions to the exact V3 record class. Neutral and
inconclusive outcomes do not train a usefulness label. A class needs four or
more independent receipts and both positive and adverse labels. Its suggested
adjustment is shrunk to one quarter of the observed confidence gap and capped at
plus or minus ten points.

Approved projections bind the repository frame to the exact integrity-valid
report. Retrieval verifies both artifacts before ranking and blocks advice on
any validation failure. Valid adjustments alter effective confidence while
preserving source, policy, freshness, governance, conflict, and explicit-use
gates.

Meta feed derives one allowlisted categorical event per independent scenario
whose confidence error meets the fixed gap threshold, and emits a class only
when the catalog repeat threshold is met. The existing Harness sanitizer and
Meta-Harness analyzer remain the privacy and proposal authority boundaries.
