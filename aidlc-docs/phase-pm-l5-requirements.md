# PM-L5 Learning Calibration And Proof Requirements

- `PM-L5-R1`: Provide deterministic learning-on/control scenarios for every
  Learning V3 class with later observed outcomes and tamper-evident provenance.
- `PM-L5-R2`: Measure precision, false interventions, confidence calibration,
  correction cycles, review time, and token overhead without generalized claims.
- `PM-L5-R3`: Calibrate class confidence only from validated later PM-L3 receipt
  outcomes with a minimum sample, mixed labels, bounded adjustment, approval,
  and repository-frame integrity.
- `PM-L5-R4`: Fail closed when an applied projection, its report, or its project
  frame is missing, changed, malformed, or incompatible.
- `PM-L5-R5`: Feed Meta-Harness only repeated allowlisted categorical evidence;
  exclude raw content, identity, paths, receipt IDs, and exact measurements.
- `PM-L5-R6`: Ship the CLI, schemas, package/release ownership, documentation,
  and positive, negative, privacy, tamper, compatibility, and reproducibility
  regression checks as one completed phase.

No dependency change is required. Calibration adjusts retrieval confidence only;
it grants no advice-use, implementation, command, Git, release, or acceptance
authority.
